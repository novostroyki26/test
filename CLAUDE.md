# CLAUDE.md

Минимальный FastAPI-сервис (Python 3.11+). Песочница для облачных сессий Claude Code.

## Команды

- Установка: `pip install -e ".[dev]"`
- Запуск: `uvicorn app.main:app --reload`
- Тесты: `pytest -q`
- Lint: `ruff check . && ruff format --check .`
- Typecheck: `mypy`

## Структура

- `app/` — код сервиса, `app/main.py` — точка входа и эндпоинты.
- `tests/` — pytest, по файлу на эндпоинт.
- Не менять без необходимости: `pyproject.toml` (зависимости и конфиги), `.gitignore`.

## Правила

- Работать только в отдельной ветке; не коммитить и не пушить в `main`, не делать merge.
- Не добавлять зависимости без явной просьбы.
- Не хранить секреты в репозитории; настройки только через переменные окружения.
- Безопасные команды: всё из раздела «Команды», `git status/diff/log`, `git commit`, push в свою ветку.
- Запрещено: `git push --force`, удаление веток, `rm -rf` вне временных файлов, доступ к production-данным.

## Задача готова, когда

1. `pytest -q`, `ruff check .`, `ruff format --check .` и `mypy` проходят.
2. На каждое новое поведение есть тест.
3. Изменения закоммичены в рабочую ветку и запушены; открыт PR в `main` с кратким описанием и результатами проверок.
